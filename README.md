# منصة معتمد — تأهيل فروع دار مكة

لوحة لرفع وثائق ومشاريع الفروع (مكة المكرمة، جدة، المدينة المنورة، الباحة، المخواة) لاستكمال التأهيل على منصة معتمد — بدون تسجيل دخول.

- **الموقع:** https://ebom2030-gif.github.io/mutamad/
- **روابط الفروع:** `?b=makkah` · `?b=jeddah` · `?b=madinah` · `?b=baha` · `?b=mikhwah`
- **الخادم:** `Code.gs` + `appsscript.json` (Google Apps Script «منصة معتمد») — البيانات في Google Sheet «منصة معتمد - قاعدة البيانات»، والملفات في فولدر «منصة معتمد» على Google Drive مرتبة حسب الفرع والمتطلب.
- **نسخة احتياطية:** أسبوعية كل خميس للشيت داخل نفس الفولدر.
